Progression rule

Try +1 rep first; sometimes +2.

Only increase an exercise at the next weekly check-in if every set was smooth, pain-free and controlled. Add just 1 rep per set at first. Add a second only when it still feels easy. If form slips, keep the same target or reduce it. For timed holds, add 5 seconds instead. Do not increase pull-up reps and sets at the same time.

Phases

Days 1–14: learn technique · Days 15–28: gradual progress · Days 29–42: steady strength · Days 43–56: skill and control · Days 57–58: easy recovery and review.
